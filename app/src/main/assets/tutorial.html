How to use

One trick, different drawings. Changing the set only changes the picture that appears.

Numbers are the default example. For included drawings, use the three-column guide below.

Perform the trick

  1. Ask someone to think of a number or picture from the set you selected.
  2. Tap the palette, choose a color and line width, then tap Apply. Tap Custom for more colors.
  3. Sketch naturally, then press and hold the palette. The black screen looks switched off but is still listening for touches.
  4. When they name their choice, quickly double-tap its area as shown below. The matching drawing appears.

Remember

  • Apply or leave the color panel to save your settings. Cancel only discards your current changes.
  • Both taps must land in the same area. Grids and tips stay hidden during a real performance.

Choose Practice Again on the home screen to learn from the beginning. Practice uses the default numbers 1–9.

Canvas Magic 사용 튜토리얼

마술 흐름

  1. 관객에게 1~N 사이의 숫자를 마음속으로 생각하게 합니다.
  2. 앱에서 색상을 선택한 뒤, 캔버스에 자연스럽게 선 몇 번 그리는 척 연출합니다.
  3. 색상 버튼을 길게 누르기로 마술 모드를 시작합니다.
  4. 관객이 숫자를 말하면, 해당 숫자 페이지를 더블탭하여 선택합니다.
  5. 앱이 자동으로 해당 숫자에 맞는 드로잉을 재생합니다.

팁

  • 길게 누르기 전, 화면을 살짝 스크롤하거나 도형을 바꾸는 등 자연스러운 동작으로 시선을 분산시키세요.
  • 더블탭은 화면 어딘 눌러도 되지만 실수 방지를 위해 화면 중앙 근처를 권장합니다.
  • 조명이 어두운 곳에서는 화면 밝기를 높여 가시성을 확보하세요.
